# Referência visual

Os três conceitos preservados nesta pasta orientam a identidade da V1:

- `client-dashboard-concept.png`: painel principal do cliente;
- `mobile-issuance-concept.png`: emissão simplificada em celular;
- `admin-dashboard-concept.png`: visão operacional do escritório.

A implementação mantém a hierarquia, a paleta azul-marinho/verde, os avisos de homologação e as ações principais. Elementos puramente decorativos foram reduzidos para deixar o produto mais simples e sério.
